# Arab Sportswashing Timeline — Feature Report

## 1. Project Overview

Arab Sportswashing Timeline is an interactive web application that documents major sportswashing events connected to Gulf and Arab states from 2008 to 2024. It presents a chronological timeline of 12 key events across six sport categories (Soccer, F1, UFC, Wrestling, Golf, Athletics) and three countries (UAE, Qatar, Saudi Arabia), allowing users to explore how high-profile sports investments serve as soft-power tools.

## 2. Features

### 2.1 Timeline Navigation

The main page displays all events in chronological order, grouped by year. A year navigation sidebar on the left allows users to jump to any year with a single click. The active year is automatically highlighted with a glow effect as the user scrolls through the timeline.

### 2.2 Event Cards

Each event is presented as a card containing:

- Event title and sport category label (color-coded)
- Date and country
- Cover image
- Descriptive text explaining the event's background

### 2.3 Filtering

A filter bar at the top provides two ways to narrow down events:

- **By sport category**: Soccer, F1, UFC, Wrestling, Golf, Athletics
- **By country**: UAE, Qatar, Saudi Arabia

Filters update the timeline instantly. A "Clear" button resets all active filters.

### 2.4 Impact Analysis Panel

Each event card has an "Impact Analysis" button. Clicking it opens a side panel that displays a detailed analysis of the event's broader political and social significance. Clicking again closes the panel.

### 2.5 Related Event Navigation

Events that are thematically connected show related event tags at the bottom of each card. Clicking a tag automatically scrolls the timeline to the related event, enabling users to trace chains of connected events across years.

### 2.6 Text Selection

All text content on the page — titles, descriptions, and analysis — is selectable, allowing users to copy information for reference.
